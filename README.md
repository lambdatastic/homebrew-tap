# Lambdatastic Tap

## How do I install these formulae?

`brew install lambdatastic/tap/<formula>`

Or `brew tap lambdatastic/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "lambdatastic/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
